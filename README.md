# 🎓 Synoptic Project — Final Year Dissertation

**Manchester Metropolitan University | 2025**

## Overview

This is my final year dissertation project, completed as part of the BSc Software Engineering programme at Manchester Metropolitan University. The project required independently specifying, investigating, and solving a real-world challenge through the design and implementation of a creative software product.

It was assessed through two elements: the **Product** (the software itself) and the **Demonstration** (a 10-minute recorded showcase).

## What Was Done

- Independently defined a project brief, identifying a problem and proposing a software solution
- Designed and developed a substantial software product from concept through to working implementation
- Produced a comprehensive project report covering:
  - Project aims and objectives
  - Methodology and development approach
  - Technical implementation details
  - Evaluation and critical reflection on outcomes
- Delivered a 10-minute video demonstration showcasing the working product and explaining the design rationale

## Project Scope

The creative piece takes the form of a software product. The nature and focus of the project was self-directed, allowing for exploration of a specific area of interest within software engineering.

## Skills Demonstrated

- Independent research and problem solving
- Full software development lifecycle (specification → design → build → evaluation)
- Technical writing and documentation
- Presentation and communication of complex technical work
- Critical reflection and self-evaluation

## Assessment Structure

| Element | Description |
|---|---|
| Product | Working software implementation |
| Demonstration | 10-minute recorded video with slides and live demo |
| Report | Written document covering aims, methodology, and outcomes |
